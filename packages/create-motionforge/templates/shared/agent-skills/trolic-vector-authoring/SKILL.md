# Trolic Vector Authoring

## Inputs
Read the current Trolic AGENT-CARD.md and AI-AUTHORING.md from the installed checkout.

## Procedure
1. Use stable IDs and explicit positions; reuse def/use, styles, repeat and batch instead of repeated literals.
2. Compile with the installed compiler and validate the delivery profile before adding detail.
3. Inspect sampled SVGs at start, midpoint and end; compare silhouette, hierarchy and palette.
4. For edits return minimal revision-aware patches and receipts rather than rewriting source.

## Acceptance gate
Editable source, compiler/profile report and inspected representative frames.

## Avoid
No invented text, blur, masks or universal Lottie support. Host-only effects belong in MotionForge.

## Shared references
Read `../../../agent-integration/AGENT-CONTRACT.md` relative to this skill directory, then only the task-relevant references listed there. Run shared scripts from the repository root.
