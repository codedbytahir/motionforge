# Storyboard Pacing

## Inputs
Product truth, main audience, runtime and proof assets.

## Procedure
1. Show the product early; assign one clear message per shot.
2. Budget actual reading time and remove duplicate claims before accelerating footage.
3. Alternate visual scale and selected backgrounds while preserving brand consistency.
4. Review a silent rough cut for comprehension and trim dead time before adding sound.

## Acceptance gate
Beat sheet with frame ranges, copy, demonstration and transition motivation.

## Avoid
A 34-second reference is not a universal duration rule; prioritize the requested platform and content.
