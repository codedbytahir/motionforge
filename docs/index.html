Know what
you’re shipping.

Good tooling should make its limits as clear as its possibilities.

Is offline rendering production-ready?

Not yet. Container muxing, audio synchronization and general frame-readiness need further implementation and testing. The next candidate disables unfinished export paths rather than inventing a successful output.

Does this page run the editor?

No. This is a static GitHub Pages landing page. It links to the source and shows an existing demo; no hosted rendering service is implied.

What is the license?

The repository and library carry the MIT license. Check dependency and asset licenses for your own distribution. Read the license.
