# Audio Direction

## Inputs
Narrative beats, audio provenance, target platform and user loudness preferences.

## Procedure
1. Prefer a coherent score and silence over repeated transition effects.
2. Use SFX only for a meaningful event, synchronize to the event frame, and fade tails.
3. Measure decoded peak and integrated loudness with available tools; document actual measurements and chosen targets.
4. Check speech intelligibility if present, headphone and quiet-speaker playback, final fade and clipping.

## Acceptance gate
Provenance, cue list and decoded mix measurements; no unsupported copyright guarantees.

## Avoid
Do not add a whoosh at every cut. Never infer platform loudness compliance from sample peak alone.
